# Dark Forest Adventure

TaeQ Yoon

A text adventure game made for the Software 1 course. The player explores a dark forest, moves between places and collects items.

## Files

- `module_3_project_1.py` - Project 1: asks the player's name and age
- `module_5_project_2.py` - Project 2: age check and main menu
- `module_7_project_3.py` - Project 3: menu functions and inventory list
- `module_12_project_4.py` - Project 4: main program that uses the classes
- `game/` - package for the game classes
  - `item.py` - Item class (name, weight)
  - `room.py` - Room class (name, item)
  - `player.py` - Player class (name, age, items, location) with the methods move() and collect_item()

## How to run

Run `module_12_project_4.py` from the project folder. Players under 12 can't play.

## Commands

look, move, collect, inventory, lopeta
